Vessel 0.3.2 fixes the account selector styling on Portfolio review.

The account picker now keeps its border, field background and typography beside
the Portfolio and Asset filters. Search and account selection behave as before.

GitHub Actions now runs checks and publication only for release tags, conserving
runner minutes. Branch pushes and pull requests rely on local checks.

## Upgrading from 0.3.1

Back up the installation, set `VESSEL_VERSION=0.3.2` and recreate the services
with matching API and web images, preserving existing overlays. Both workers use
the API image. There are no new database migrations or configuration changes.

For earlier versions, follow the existing
[upgrade requirements](https://github.com/sloppitty/vessel/blob/v0.3.2/deploy/README.md#upgrade),
including the v0.3.0 order-identity restriction and v0.3.1 migrations.

## Images

Linux amd64:

- `skorcius/vessel:api-0.3.2`
- `skorcius/vessel:web-0.3.2`

The Release workflow verifies both versioned images before moving `api-latest`
and `web-latest`. Publication does not deploy or migrate any installation.

## Known limits

Existing limits remain: Wallet mode is opt-in with registration kept `Closed`
pending real-wallet acceptance, and funding remains separate from execution net.

See the [changelog](https://github.com/sloppitty/vessel/blob/v0.3.2/CHANGELOG.md).
