Trading mode switch

Eight replacements for the Trading mode select in the sidebar, for the owner to choose from. Every mock is live: switch with the option's own control, collapse the sidebar to the icon rail, or view it at phone width. The sticky header with a breadcrumb and the Paper strip are being built separately and appear here only so each option is judged in context. Plays rows no longer carry a Paper chip, so the switch and the strip are the only mode signals.

  • Paper tone: --warning mixed 72% with --muted-foreground, plus washes and lines from the same mix. No new colours, so every theme follows (try Daylight below).
  • Icons: an anchor for Real and a paper boat for Paper. Option 2 uses a flask to show the alternative.
  • Unsaved work: with “Simulate unsaved Play work” on, every option leads into the same confirmation instead of window.confirm, and the control shows the pending choice until you answer.
  • Paper unavailable: the control is not rendered at all when Paper is off in Settings or the server does not support it.

    Recommendation

    A suggestion for the owner; any option can be built.

    1. 4 · Environment pill.

      Switching reloads a different workspace (its own accounts, portfolios and Plays), which is what the established environment pattern means. It is the only option visible on a phone without opening the menu, the collapsed rail does not affect it, and it sits directly above the Paper strip, so the control and its explanation read together. The sidebar loses a control instead of gaining one. Costs: it waits for the new header, and switching takes two clicks, which suits a rare, workspace-wide change.

    2. 1 · Segmented control.

      If you prefer a one-click toggle that stays in the sidebar. Both modes are named, it folds into the rail as a vertical pair, it is the smallest change from today and the cheapest to build and test.

    Either works with the paper-boat icon. Option 5's mark change could be added later for extra ambience.
